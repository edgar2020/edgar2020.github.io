    Data Exploration

    DUE Wednesday 10/21 10:50 am

    This section is to be done Individually

    Start looking for data now, while we are still learning the tools. Pick a topic you are curious about and look for a data set you can load into Python. Some good places to look:

    • Kaggle Datasets - thousands of data sets on almost any topic
    • data.gov - US government data
    • TidyTuesday - a new, cleaned up data set every week
    • UCI Machine Learning Repository
    • Pew Research Center - survey data (you need a free account to download) Your major!
    • Ask a professor in your field what data they use.

    A good data set for this class:

    • loads into a DataFrame with pd.read_csv() or pd.read_excel()
    • has at least a few hundred rows, and a mix of numerical and categorical variables
    • comes with an explanation of what each column means (sometimes called a data dictionary)
    • tells you where the data came from and who collected it

    Make a folder called FinalProject in your repo and save your data there. NOTE - GitHub will not take a file bigger than 100 MB. If your data is that big, come talk to me.

    Data Exploration Deliverable

    Make a notebook called DataCheckIn.ipynb in your FinalProject folder. In it:

    1. Say where your data came from (a link, and who collected it).
    2. Load your data into a DataFrame.
    3. Run .describe() on your data.
    4. Run .value_counts() on at least one categorical column.
    5. Make one plot.

    Push it to your repo. This is a quick look, not a finished analysis! We will use this notebook again during Data Ethics week, so make sure your data really loads.

    Project Proposals

    This section is to be done individually.

    Your project proposal should reflect your own individual work and should not overlap too much with the work of your peers. Project proposals should take the form of a JupyterLab notebook that includes the following sections:

    • Introduction and Background for the problem you are interested in.
      • What is the question you hope you can answer?
      • Why is the question important to you?
      • What are you hoping to achieve with the project?
    • Description of the data.
      • Where did you get your data?
      • What data is found in your data set?
      • Are there any ethical concerns with using the data or how the data was obtained?
      • Is there a public location where the data is freely available? If so where? If not why?
    • Initial Exploratory Data Analysis.
      • Definition of all variables (or explanation for why you are not considering some variables)
      • Descriptive statistics for the data set, counts of the variables, value counts (frequency tables) for each categorical variable of interest.
      • Plots that help a reader understand your data.
      • Initial analysis to answer initial data questions.
    • Proposal for further study.
      • What larger questions would you like to try to answer?
      • What do you think you might be able to predict with your data?
      • Are there any larger impacts that your study might have?

    Push your proposal notebook to the FinalProject folder in your repo by Sunday 11/8 11:59pm. Whatever is in your repo at the deadline is what gets graded. If it’s pushed, it’s submitted.

    Before you push, restart the kernel and run all the cells (Kernel > Restart Kernel and Run All Cells) to make sure your notebook runs from top to bottom. If it needs a data file, push the data file too, or read the data straight from a web address. Your notebook should contain just as many words and as much description of the problem/results as it does code.

    If you already have a group of people you plan to work with - please list their names at the end of the proposal. I read all of the proposals and then put you into groups, usually around similar topics or data.
